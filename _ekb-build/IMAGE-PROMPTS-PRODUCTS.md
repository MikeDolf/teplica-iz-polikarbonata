# НАБОР B. Широкие кадры материалов, 16:9

**B1. Чернозём**
```
Большая куча чернозёма на открытой площадке. Материал очень тёмный,
влажный, комковатый. Рядом воткнута штыковая лопата. Утро, пасмурно,
укатанная площадка. Общий план, куча занимает центр кадра.
```

**B2. Перегной**
```
Куча перегноя на площадке: тёмная однородная рассыпчатая масса, похожая
на землю. Рядом строительная тачка, наполненная перегноем. Пасмурный
день, утоптанная земля.
```

**B3. Торф**
```
Куча низинного торфа на площадке, тёмно-бурая, влажная, мелкой фракции.
Поверхность кучи неровная, со следами ковша. Пасмурный день, вдалеке
край забора и деревья.
```

**B4. Кислый торф**
```
Куча верхового торфа: рыжая, волокнистая, заметно светлее обычного
грунта. Рядом стоит саженец голубики в контейнере и лежит совок.
Дачный участок, пасмурный день.
```

**B5. Торфогрунт**
```
Куча торфогрунта на площадке, коричневая рыхлая смесь. Рядом стоят
несколько открытых мешков с тем же материалом. Пасмурно, утоптанная
земля.
```

**B6. Опилки**
```
Большая куча светлых древесных опилок на площадке. Материал заметно
светлее всего вокруг, рыхлый, объёмный. Рядом деревянные вилы. Пасмурный
день, край забора вдалеке.
```

**B7. Навоз**
```
Куча перепревшего навоза на утоптанной земле, тёмная, рыхлая, с редкими
соломенными включениями. Рядом воткнуты вилы. Позади край поля и низкое
пасмурное небо.
```

**B8. Навоз коровий**
```
Куча перепревшего коровьего навоза: плотная, влажная, почти чёрная,
однородной структуры. Рядом совковая лопата. Пасмурный день, площадка.
```

**B9. Навоз конский**
```
Куча перепревшего конского навоза: рыхлая, волокнистая, светлее
коровьего, с ясно различимой соломой. Рядом вилы с деревянным черенком.
Край дачного участка, берёзы в расфокусе.
```

**B10. Плодородный грунт**
```
Куча плодородного грунта на площадке, тёмно-коричневая рыхлая смесь.
На переднем плане участок с уже разровненным слоем грунта под газон,
рядом лежат грабли. Пасмурный день.
```

**B11. Земля в мешках**
```
Ряд плотно набитых мешков с землёй стоит вдоль забора дачного участка,
около пятнадцати штук. Мешки серые и белые, полностью без надписей и
этикеток. Один мешок открыт, видна тёмная просеянная земля. Пасмурно.
```

# Порядок генерации

1. **Набор A целиком** — сразу заменит текстуры в полосе и каталоге на
   всех 114 страницах. Самый заметный эффект на единицу работы.
2. **Набор C** — три машины в блок объёмов, тоже на всех страницах.
3. **Набор B** — по убыванию: чернозём, перегной, торф, опилки.
4. **Набор D** — хаб и общие блоки.

# Проверка перед отправкой

1. **Номера и надписи на технике.** Наборы C и D. Если проступили —
   перегенерируй, выдуманный госномер выглядит плохо.
2. **Геометрия машин.** Колёса разного размера, невозможная кабина,
   лишние оси. Частая беда, смотри внимательно.
3. **Мешки без этикеток.** B11 и C1: любые надписи на мешках надо убрать.
4. **Разное небо.** Не должно быть одинаковым во всех 28 кадрах.
