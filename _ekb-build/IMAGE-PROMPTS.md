# Промпты для генерации фотографий

Эталон: mosnerud.ru. Оттуда взяты три рабочих типа кадра:
1. Куча материала на площадке, естественный свет, техника на фоне.
2. Рука, держащая материал крупным планом — показывает структуру.
3. Макро текстуры, заполняющее весь кадр.

Формат под сайт: **квадрат 1:1** для карточек, **16:9** для шапок статей.

---

## Стилевой префикс

Ставь его перед каждым промптом, чтобы все картинки вышли в одном стиле:

```
Реалистичная документальная фотография, снято на зеркальную камеру,
объектив 35 мм, диафрагма f/5.6, естественный дневной свет, пасмурное
небо без резких теней. Средняя полоса России, Урал, конец весны.
Приглушённые natural-цвета, без HDR, без глянца, без обработки под
рекламу. Никакого текста, надписей, логотипов и водяных знаков.
Лиц людей в кадре нет.
```

**Хвост** — добавляй в конец каждого промпта:

```
Соотношение сторон 1:1. Фотореализм, без иллюстративности, без 3D-рендера.
```

## 1. Конский навоз как удобрение

```
Куча перепревшего конского навоза на краю дачного участка. Материал
рыхлый, волокнистый, тёмно-коричневый, видны соломенные включения и
частицы подстилки. Рядом воткнуты вилы. На заднем плане деревянный
забор и берёзы, слегка расфокусированы.
```

## 2. Коровий навоз как удобрение

```
Куча перепревшего коровьего навоза на утоптанной земле. Масса более
плотная и влажная, чем конский навоз, тёмная, почти чёрная, однородной
структуры, с блеском от влаги. Рядом лежит совковая лопата. Позади
край поля и низкое пасмурное небо.
```

## 3. Навоз или перегной: что лучше

```
Две кучи органики рядом на площадке, для сравнения. Слева свежий навоз:
рыхлый, светлее, с ясно различимой соломой. Справа перегной: однородная
тёмная рассыпчатая масса, похожая на землю. Между кучами воткнута
лопата. Видна разница в структуре и цвете.
```

## 4. Какой навоз лучше: конский, коровий, куриный

```
Три небольшие кучки органических удобрений в ряд на деревянном щите,
вид сверху под углом. Слева светло-коричневая волокнистая с соломой,
в центре тёмная плотная влажная, справа мелкие серо-коричневые гранулы.
Между кучками расстояние, каждая хорошо различима.
```

## 5. Чернозём или плодородный грунт

```
Две кучи грунта рядом на площадке. Слева чернозём: очень тёмный, почти
чёрный, жирный, комковатый, блестит от влаги. Справа плодородный грунт:
светлее, рыхлее, с видимыми частицами торфа и песка. Разница в цвете и
структуре читается сразу.
```

## 6. Сколько стоит чернозём

```
Большая куча чернозёма на открытой площадке, рядом стоит самосвал с
поднятым кузовом, из которого только что выгрузили грунт. Чернозём
тёмный, влажный, комковатый. Утро, пасмурно, площадка укатанная,
местами лужи. Общий план.
```

## 7. Грунт для теплицы

```
Внутренний вид поликарбонатной теплицы весной. Свежие грядки с тёмным
рыхлым грунтом, ровно выровненные граблями, посадок ещё нет. Рядом с
грядкой стоит ведро с грунтом и садовые грабли. Мягкий рассеянный свет
через поликарбонат.
```

## 8. Сколько стоит навоз

```
Куча перепревшего навоза на площадке, рядом мешки той же органики,
поставленные в ряд. Показан выбор между россыпью и фасовкой. Пасмурный
день, утоптанная земля, вдалеке край забора.
```

## 9. Куриный помёт как удобрение

```
Гранулированный куриный помёт крупным планом, насыпан горкой на грубую
деревянную доску. Гранулы серо-коричневые, цилиндрические, около
4-5 мм, матовые, сухие. Часть гранул рассыпана вокруг горки. Макросъёмка,
малая глубина резкости.
```

## 10. Конский навоз для клубники

```
Грядка клубники, замульчированная перепревшим конским навозом. Кусты
с зелёными листьями и завязавшимися ягодами, между рядами лежит слой
тёмной рыхлой органики. Естественный дневной свет, вид сверху под
углом 45 градусов.
```

## 11. Гранулированный навоз

```
Гранулированное органическое удобрение крупным планом, высыпано из
бумажного пакета на деревянную поверхность. Гранулы тёмно-коричневые,
плотные, ровные, около 5 мм. Пакет виден частично, без надписей и
этикеток. Макросъёмка.
```

## 12. Когда вносить навоз

```
Осенняя грядка после перекопки, в почву заделан перепревший навоз.
Земля тёмная, крупными комьями, местами видны включения органики.
На краю грядки лежат вилы. Поздняя осень, пасмурно, рядом сухая трава
и облетевшие ветки.
```

## 13. Сколько стоит перегной

```
Куча перегноя на площадке, тёмная однородная рассыпчатая масса, похожая
на землю, без соломы и включений. Рядом строительная тачка, наполненная
перегноем. Пасмурный день, утоптанная площадка.
```

## 14. Настой из навоза

```
Пластиковая бочка на 200 литров на дачном участке, наполненная тёмной
жижей настоя, сверху плавает пена. Рядом лежит деревянная палка для
перемешивания и стоит лейка. Позади грядки и куст смородины. День,
рассеянный свет.
```

## 15. Хаб раздела «Доставка грунта»

```
Панорама площадки поставщика сыпучих материалов. Несколько куч разного
грунта в ряд: тёмный чернозём, коричневый торф, светлые опилки. Между
ними проезд, вдалеке фронтальный погрузчик. Широкий план, пасмурное
небо, рабочая обстановка без людей.
```

## Товарные страницы: макро текстуры

Для карточек каталога, как круглые фото песка на эталоне. Общий шаблон:

```
Макросъёмка текстуры {МАТЕРИАЛ}, заполняет весь кадр, вид строго сверху.
Естественный рассеянный свет, видна зернистость и структура. Малая
глубина резкости по краям. Соотношение сторон 1:1.
```

Подставляй:

| Страница | {МАТЕРИАЛ} |
|---|---|
| Чернозём | влажного чернозёма, очень тёмного, почти чёрного, комковатого, жирного |
| Перегной | перегноя, тёмно-коричневого, однородного, рассыпчатого |
| Торф низинный | низинного торфа, тёмно-бурого, влажного, мелкой фракции |
| Кислый торф | верхового торфа, рыжего, волокнистого, из сфагнового мха |
| Торфогрунт | торфогрунта, коричневой рыхлой смеси торфа с песком |
| Опилки | свежих древесных опилок, светлых, хвойных, крупной стружки |
| Навоз коровий | перепревшего коровьего навоза, тёмного, плотного |
| Навоз конский | перепревшего конского навоза, с соломенными волокнами |
| Плодородный грунт | плодородного грунта, тёмно-коричневой рыхлой смеси |

## Кадр «в руке»

Самый убедительный тип с эталона, по одному на товар:

```
Мужская рука без перчатки держит горсть {МАТЕРИАЛ}, ладонь раскрыта,
часть материала просыпается между пальцами. Фон размыт: куча того же
материала. Естественный дневной свет, пасмурно. Видна структура и
влажность. Лица нет, только рука и предплечье в рабочей одежде.
Соотношение сторон 1:1.
```

## Что проверить перед публикацией

1. **Пальцы и руки.** Слабое место генерации: лишние пальцы, неверные суставы. Кадры «в руке» проверяй внимательно.
2. **Текст.** Если на технике, мешках или заборе проступили буквы — перегенерируй, читаемая абракадабра выдаёт ИИ мгновенно.
3. **Техника.** Погрузчики и самосвалы часто выходят с неправильной геометрией: колёса разного размера, невозможная кабина. Лучше держать их на дальнем плане и в расфокусе.
4. **Однообразие.** Если все картинки выйдут с одинаковым небом и ракурсом, набор будет выглядеть сгенерированным. Проси разные ракурсы и время суток.

## Что прислать обратно

Файлы в PNG или JPG, как отдал ChatGPT, без обрезки. Имена любые,
главное скажи, какая картинка к какой статье. Я обрежу под нужные
пропорции, сожму в WebP, пропишу alt и подключу к страницам.
